## 1. 家族实验前后评分定义改变

**成立。这是四条中最根本的一条。**

`src/train/train_family_metric.py:288`：

```python
score_mode = "binary" if float(method_cfg.get("alpha", 0.0)) == 0.0 else "metric"
metrics = evaluate_fold(frame, embeddings, model, train_frame, family, seed, score_mode=score_mode)
```

`projection_scores()` 据此分岔（同文件 190-225 行）：

- `score_mode == "binary"` → `torch.softmax(logits, dim=1)[:, 1]`，即二元分类头输出的非法概率；
- 否则 → 由训练集中丹麦各家族质心构成矩阵 `c`，返回 `(q @ c.T).max(axis=1)`，即与已见家族质心的最大余弦相似度。

`configs/week11.yaml:47-58` 定义的四个臂：A1 `alpha: 0.0`、A2 `alpha: 0.5`、A3 `alpha: 1.0`、A4 `alpha: 0.5`。**评分方式由同一个 α 开关同时决定**，因此 A1 与 A2/A3/A4 之间同时更换了方法与度量。

阶段五基线的 0.622 同样来自非法概率（`src/train/multi_scenario_eval.py:679-701` 的 `_hard_eval_metrics`，`y_score = pred_prob_illegal`）。故 0.622 与 0.126 之间隔着一次评分函数替换，其差值不能归因于监督对比损失。

释出产物已带 `score_mode` 列，可直接核对：

| 臂 | α | binary_weight | score_mode | 两族均值 AUC |
|---|---|---|---|---|
| A1_only_binary | 0.0 | 1.0 | **binary** | ggbet 0.620 / tsars 0.486 |
| A2_main | 0.5 | 1.0 | **metric** | ggbet 0.078 / tsars 0.074 |
| A3_only_supcon | 1.0 | 0.0 | **metric** | ggbet 0.082 / tsars 0.089 |
| A4_shuffled_family | 0.5 | 1.0 | **metric** | ggbet 0.308 / tsars 0.301 |

**处置**：5.3 改写，撤回 0.622−0.126 的相减与由此得出的"退化 0.496"，逐臂标注评分方式；图 7 题注注明两列评分函数不同、不构成方法优劣比较。

## 2. 未见家族的正类定义与评分方向不匹配

**成立，且比审稿意见描述的更彻底——负样本正是定义质心的那批样本。**

`evaluate_fold()`（237-252 行）：

```python
positives = frame[frame["p1_family_id"].astype(str).eq(heldout_family)]          # 留出家族 = 正类
negative_pool = frame[
    frame["jurisdiction"].eq("Denmark") & (frame["label"] == 1)
    & frame["p1_family_id"].notna()
    & ~frame["p1_family_id"].astype(str).eq(heldout_family)                       # 其余丹麦非法家族 = 负类
]
```

而 `projection_scores()` 的质心由 `train_frame` 中的丹麦非法家族按 `p1_family_id` 分组求均值得到——**即负样本所属的那些家族**。于是标签要求"未见家族得高分"，评分却度量"像已见家族的程度"，两者方向相反；AUC 落在 0.5 以下是该构造的必然结果，而非关于监督对比学习的证据。

释出数据直接印证：全部 metric 臂的 `negative_score_mean` 系统性高于 `positive_score_mean`（A2 全 35 次运行平均 0.958 对 0.799）。

按评分实际优化的方向（已见家族成员为正类）重读同一批分数：

| 臂 | 原方向均值 | 重读均值 |
|---|---|---|
| A2_main（7 族 35 次） | 0.126 | **0.874** |
| A3_only_supcon | 0.085 | 0.915 |
| A4_shuffled_family（标签打乱） | 0.305 | 0.695 |

真实家族标签相对打乱标签有约 +0.22 的差距，说明度量头确实学到了可分的家族结构。

**附带发现**：预声明假设 H_P1d 要求 `A2 − A4 ≥ 0.05`，原报告为 −0.230（ggbet）与 −0.227（tsars），记为未通过；按重读方向则为 +0.230 与 +0.227。**本文不据此改判该假设**——预声明判定以登记时协议为准，且该协议本身含有第 3 条的训练测试重叠，重读值同样不足以作为通过依据。该重读仅作为事后诊断释出。

**处置**：5.3 写入方向错配的完整说明与重读值，并明确"不据此改判预声明假设"。

## 3. 家族实验的测试负样本未排除出训练与质心构建池

**成立，且与旧流程形成直接对照。**

阶段七 `prepare_tensors()`（99-108 行）只剔除留出家族：

## 4. "SupCon 导致原分类能力退化"缺少支持

**成立。该表述在本实现中既无测量、也不可能成立。**

结构上：`src/models/family_metric_head.py` 的 `FamilyDualHead` 中，`binary_head` 与 `family_head` 各自直接作用于输入张量，**不共享任何可训练参数**；输入是 `load_frozen_embeddings()` 读入的冻结 HeCo 嵌入。总损失 `loss = binary_weight * ce + alpha * sup` 中，`sup` 只依赖 `z = family_head(x)`，对 `binary_head` 参数的梯度恒为零。二者唯一的耦合是 `train_dual_head()` 以合并损失做早停选点（`if current < best_loss`），即 α 会改变选中的轮次，但不会改变二元分类的表示。

测量上：由于 α>0 时 `score_mode` 自动切到 `metric`，**公开产物中不存在 α>0 条件下二元分类头的任何评测值**。该主张因此没有任何数据支撑。

**处置**：5.3 撤回"监督对比学习损害了原有分类能力"的表述，并写明双头结构与"无 α>0 分类头测量值"这一事实。

## 6. 表 7"六项均经 Holm 校正后显著"缺乏实现支持

**已在 v11 撤回该声称；本轮把推断式说明替换为实算结果。**

`analysis/week8_acceptance.py` 与 `src/explain/` 下确无 Holm 实现，E1 汇总只输出未校正的 `p_value` 与 `significant_05`。v11 的表 7 题注已改为"未经多重比较校正"，但校正说明写作"最小阈值为 0.05/20=0.0025"，这是族内最小阈值而非该行对应的阈值，推理链不严谨。

本轮以 `analysis/supp_protocol_audit.py` 对全部 20 个比较实算 Holm 步降：

| Holm 秩 | 情境 × 边类型 | 原始 p | 阈值 α/(m−k+1) | 通过 | 校正后 p |
|---|---|---|---|---|---|
| 1 | T2_ON × hosted_on | 0.000 | 0.00250 | 是 | 0.0000 |
| 2 | T2_ON × registered_via | 0.000 | 0.00263 | 是 | 0.0000 |
| 3 | T2_PH × registered_via | 0.000 | 0.00278 | 是 | 0.0000 |
| 4 | T2_PH × uses_cert | 0.000 | 0.00294 | 是 | 0.0000 |
| 5 | T3_FR × uses_cert | 0.000 | 0.00313 | 是 | 0.0000 |
| **6** | **T1_DK × registered_via** | **0.028** | **0.00333** | **否** | **0.4200** |
| 7–20 | 其余 | 0.142–1.000 | — | 否 | 1.0000 |

即 **20 个比较中 5 个通过、丹麦注册商一行校正后 p=0.420 不通过**，与审稿意见一致。

但需同时指出：那 5 个"通过"来自 p=0.000，而本文所用自助 p 值由重采样均值相对零点的位置反演得到，5 个种子同号时必然取 0（见 4.4 的同一论证），对其施加 Holm 校正不构成有效的显著性程序。表 7 因此仍只作方向一致性的描述性证据。

**处置**：表 7 题注替换为实算结果并给出记录文件路径；5.2 正文把"6 个显著效应"改为"6 个方向一致的效应"、给出丹麦一行的校正后 p，并限定该情境仅作方向旁证；1.3 的"registered_via 边在丹麦/菲律宾两个目标域上呈现统计显著的负迁移效应"相应收紧。
