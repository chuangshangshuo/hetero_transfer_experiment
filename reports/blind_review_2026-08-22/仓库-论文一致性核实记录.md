## 2. InfoNCE 负样本范围（论文按全体描述，实现取最难 30%）

**成立。**

`src/models/heco_head.py:77-90`：

```python
def _denominator_mask(self, similarity, positive_mask):
    if self.hard_negative_ratio <= 0:
        return torch.ones_like(positive_mask, dtype=torch.bool)
    negative_mask = ~positive_mask
    denominator_mask = positive_mask.clone()
    for row_idx in range(num_nodes):
        negatives = negative_mask[row_idx].nonzero(...).flatten()
        k = max(1, int(round(float(negatives.numel()) * self.hard_negative_ratio)))
        selected = negatives[torch.topk(similarity[row_idx, negatives], k=k).indices]
        denominator_mask[row_idx, selected] = True
    return denominator_mask
```

四份配置均为 `hard_negative_ratio: 0.30`。分母 = 正样本集 ∪ 逐锚点相似度最高的 30% 负样本；负样本选取用 `similarity.detach()`（不回传梯度）。

正样本集的构造也未在论文中写明：`src/models/view_generators.py:165-180`，4 条元路径的加权共现得分累加后取 Top-10（`top_k_positive: 10`，`min_metapath_support: 1`），且 `positive_mask` 初始化为单位阵即包含节点自身。

**处置**：式(1) 下方补写分母口径与正样本构造。

`configs/week8.yaml:180-182`：

```yaml

  feature_mode: zero_website_all

```

`src/explain/structure_vs_lexical.py:95-96` 中 `zero_website_all` 只执行 `website_x = torch.zeros_like(website_x)`，`apply_feature_mode()` 全程只触碰 `data["Website"].x`。按 `data/graphs/hetero_graph_v2_metadata.json` 的特征维度，C4 清零 Website 的 7 维，**保留 IP 20 维 + Certificate 20 维 + NameServer 3 维 + Registrar 2 维 + ExternalReference 2 维，合计 47 维基础设施属性**，且保留全部边。因此 C4 的 0.713 / 0.598 / 0.574 / 0.045 是「拓扑 + 邻居节点属性」的联合贡献，无法归给纯拓扑。

| 迁移 | 原始组 C4（`zero_all`） | 冻结组 C4（`zero_website_all`） | 相等 |
|---|---|---|---|
| T1_Nordic | 0.0451612903 | 0.0451612903 | 是 |

| T2_PH | 0.5979166667 | 0.5979166667 | 是 |
