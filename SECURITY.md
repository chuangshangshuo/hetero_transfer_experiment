# Security and Misuse Notes

This repository contains research code and aggregate results for a study of
illegal-vs-licensed website recognition. It is not an operational blocklist,
attribution system, enforcement tool, or production classifier.

Please do not use this repository to:

- identify, contact, target, or promote illegal websites;
- claim reliable illegal-family attribution;
- deploy automated enforcement without independent validation;
- infer site-level labels from aggregate tables or figures.

Potential safety concerns should be reported privately to the repository owner.
